# Relay

A reliable webhook delivery service built as a backend engineering learning project.

## Project layout

- `backend/`: Spring Boot application, Maven wrapper, and tests.
- `backend/src/main/resources/db/migration/`: SQL migrations managed by Flyway.
- `compose.yaml`: placeholder for the local PostgreSQL configuration.
- `docs/project-plan.md`: project scope, delivery contract, and milestone checklist.

## Current status

The initial project layout is in place. Database configuration and webhook delivery implementation are still pending.

Open `backend/pom.xml` as a Maven project in your IDE. The application is not yet configured to connect to PostgreSQL.
